# Changelog

## Initial public research snapshot

Development build 47 source: full C# NativeAOT integration, static IL2CPP bridge and native hooks, touch/input/audio support, bounded diagnostics, corrected map-picker receiver and color callback argument conversion. Signed Mac startup and a physical Online lobby were observed. Authentication and game-start failures remain open; see docs/KNOWN_ISSUES.md.

No binary release is included. Later experimental auth retry and settings-cleanup stages are not part of this snapshot.
