# Exact multi-argument and boolean native delegates

This optional 40-byte host/40-byte callback extension constructs actual native Action<reference,Int32,Int32-enum>, Func<reference,Boolean>, and UnityAction<Scene,Int32-enum>. Other shapes fail explicitly. Existing native delegates use owning one-token facade constructors; source callbacks use statically compiled native and NativeAOT callbacks, never runtime class injection or code generation.

Every concrete closed generic constructor/Invoke must match exact public metadata and the pinned executable association for the classified original image. The existing full candidate framework SHA/UUID guard precedes consumption of the private process-lived 88-byte callback MethodInfo records. The clear-framework independent disassembly establishes register preservation: Action3 forwards x0 self, x1 reference, w2 Int32, w3 enum, x4 metadata; Func forwards x0 self, x1 reference, x2 metadata and returns boolean; Scene2 forwards x0 self, w1 Scene, w2 enum, x3 metadata. The companion own ARM64 compiler fixture checks these source callback prototypes at integer extremes. Neither offline disassembly nor the own fixture replaces actual runtime execution proof.

Scene is accepted only when actual metadata identifies the value type UnityEngine.SceneManagement.Scene, public blittability/value-size checks report exactly four bytes, and its only instance field is Int32 m_Handle. The received four-byte compiler ABI value is boxed with the actual class through the public gateway. No private object/value field offset is read. Int32 enums require public enum/basetype metadata and exact four-byte gateway value size. Reference arguments are checked for native assignability. All managed ABI values are opaque root/class/source/registration tokens; no native object/metadata pointer crosses into C#.

Callback argument roots are borrowed for the native call. Managed codecs consume independent retained roots. Native-value codecs transfer the RuntimeObject itself into the value facade; the callback reader deliberately does not dispose that transferred root. An escaped Scene therefore remains valid until its owning facade box is released. Source callback exceptions are contained; Func returns false on failure and records the failure status.

The weak carrier/equality cache model matches the stable source identity extension. Proxy Dispose remains root-only; explicit Close tombstones the shared source across aliases. Native owners keep the carrier live. Each registry is bounded to 256; main-queue sweeps reclaim collected carriers and source/equality mappings exactly once. Capture cycles still require explicit genuine owner cleanup.

NativeCallbackScope is the explicit cleanup primitive: attach unsubscribe and Close actions, then Dispose on actual owner destruction or plugin teardown. It marks itself disposed before reentry, performs every unsubscribe before every Close in reverse registration order, clears captures, and continues all cleanup after an error before rethrowing the first error. It does not run from a finalizer and does not use disposable proxy lifetime as ownership. Scene transition is a distinct signal for DontDestroyOnLoad owners. Source component state integration must call this primitive on genuine OnDestroy/teardown; adding the primitive alone is not that integration.

The isolated actual payload creates its own delegates and boxed values, invokes the three exact families, checks Unicode/NUL Action3 arguments, true/false and exception Func results, NetworkedPlayerInfo null, an escaped boxed Scene handle/mode, proxy disposal/Close, fresh method-group removal, scope ordering/error cleanup, and root/source cleanup. It does not subscribe to SceneManager events or create/mutate a game component, lobby, player or actual scene.

Own NativeAOT fixture links the production callback/scope C# files against an original simulated host and checks callback values, boolean normalization, containment, escaping Scene root, and cleanup order. Its evidence is labeled simulated host, not IL2CPP execution. Build it with dotnet publish tests/complex_delegate_fixture/ComplexDelegateFixture.csproj -c Release -r osx-arm64 --self-contained. Production tables are independent, and NativeAction/UnityAction zero and scalar tables retain their existing sizes. Stable-source-identity patch is a prerequisite for native Registry.findSource.
